# Support

## General questions and contributions

Use the repository's GitHub collaboration surfaces for non-sensitive questions,
documentation corrections, and proposals when those surfaces are available.
Include enough context to reproduce a problem without sharing credentials,
private data, or source-restricted material.

For contribution guidance, see [CONTRIBUTING.md](CONTRIBUTING.md). For
governance questions, see [GOVERNANCE.md](GOVERNANCE.md).

## Security matters

Do not use public support channels for vulnerability details. GitHub Private Vulnerability Reporting is active and read-back verified; use the private route described in [SECURITY.md](SECURITY.md).

## Scope boundary

V1 does not provide live Jira or Confluence destination support. Any future
Jira or Confluence presentation is a fake, non-canonical preview with no
network write. Managed-provider support also cannot authorize Cloudflare,
Railway, or Supabase resource changes without active O3 authority.
